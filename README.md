# MOVA Coffee — landing page

One-page website for MOVA Coffee, Unit 10, High Cross Centre, Fountain Road, London N15 4QM.

- `index.html` — the whole site (plain HTML, no build step)
- `images/` — logo, photos and the printable menu (`mova-menu.png`)

## MOVA Miles (loyalty card)
- `miles/`: customer card · `staff/`: till tablet · `admin/`: owner admin · `privacy/`: privacy notice
- `assets/`: shared styles and scripts; settings in `assets/js/config.js`
- `supabase/schema.sql`: database, rules and functions · `tests/`: checks for the database logic
- **Setup steps: see `SETUP.md`.**

## Deploy on Vercel
Import this repository in Vercel. Framework preset: **Other**. No build command, output directory is the repo root.
